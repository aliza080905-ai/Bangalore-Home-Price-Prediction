# Bangalore Home Price Prediction 🏠💰

This is a full-stack Data Science and Machine Learning project that predicts real estate prices in Bangalore, India, based on features like area (square feet), BHK, bathrooms, and location.

## 🌟 Features
- **Interactive UI:** Clean and modern design built with HTML, CSS, and JavaScript (jQuery).
- **Dynamic Data:** Locations are auto-populated from the backend server dynamically.
- **Machine Learning Backend:** A trained Linear Regression model serves predictions instantly via a Python Flask server.

## 🛠️ Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (jQuery)
- **Backend:** Python, Flask
- **Data Science / ML:** NumPy, Pandas, Scikit-Learn, Jupyter Notebook


## 🚀 How to Run Locally

### 1. Prerequisites
Make sure you have Python installed on your system.

### 2. Setup the Backend Server
1. Navigate to the `SERVER` directory.
2. Install the required dependencies (Flask, NumPy, etc.).
3. Run the flask server:
   ```bash
   python server.py
